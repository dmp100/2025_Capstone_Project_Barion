## 🌟 **주요 기능 (Android App)**

### ⭐️ **메뉴 관리 시스템**
- **CRUD 기능**: 메뉴 추가, 수정, 삭제, 조회
- **이미지 처리**: 갤러리/카메라 연동, Base64 인코딩으로 서버 전송
- **카테고리 관리**: 드래그 앤 드롭으로 순서 변경 가능
- **실시간 동기화**: 키오스크와 실시간 메뉴 데이터 동기화

### ⭐️ **매출 분석 대시보드**
- **시각화**: Chart.js 기반 일/주/월별 매출 그래프
- **통계 분석**: 메뉴별 판매량, 시간대별 매출 분석
- **리포트 생성**: PDF 형태로 매출 보고서 생성
- **트렌드 분석**: 매출 증감률, 인기 메뉴 추천

### ⭐️ **주문 관리 시스템**
- **실시간 주문**: 키오스크에서 들어오는 주문 실시간 확인
- **주문 상태 관리**: 접수/준비중/완료/취소 상태 변경
- **알림 시스템**: 새 주문 시 푸시 알림
- **환불 처리**: 간편한 환불 및 취소 처리

### ⭐️ **직원 관리 기능**
- **직원 등록**: 직원 정보 등록 및 권한 설정
- **근태 관리**: 출퇴근 기록, 근무 시간 통계
- **급여 계산**: 시급 기반 자동 급여 계산
- **스케줄 관리**: 근무 일정 등록 및 관리

## 💡 **프로젝트 배경**

**Barion Android App**은 **배리어프리 키오스크 플랫폼**의 핵심 구성 요소로, 소상공인이 매장을 효율적으로 관리할 수 있도록 돕는 통합 관리 솔루션입니다.

### **해결하고자 하는 문제**
- 🏪 **매장 운영의 복잡성**: 메뉴, 주문, 매출, 직원 관리를 하나의 앱으로 통합
- 📊 **데이터 분석 부족**: 매출 데이터를 시각화하여 경영 인사이트 제공  
- 🔄 **키오스크 연동**: 배리어프리 키오스크와 실시간 데이터 동기화
- 💰 **비용 효율성**: 기존 시스템 대비 저렴한 비용으로 스마트 매장 관리

### **핵심 가치**
- **🎯 올인원 솔루션**: 하나의 앱으로 모든 매장 관리 업무 처리
- **📱 모바일 우선**: 언제 어디서나 매장 상황 확인 및 관리 가능
- **🤖 AI 연동**: 키오스크의 On-Device AI와 연동된 스마트 기능
- **📈 데이터 기반**: 매출 분석을 통한 데이터 기반 의사결정 지원

## 📊 **기대 효과**

1. **⏰ 업무 효율성 증대**: 통합 관리로 업무 시간 50% 단축
2. **📈 매출 증대**: 데이터 기반 의사결정으로 매출 20% 향상
3. **💰 비용 절감**: 기존 POS 시스템 대비 70% 비용 절약
4. **🤝 고객 만족도 향상**: 배리어프리 키오스크 연동으로 접근성 개선

## 🔧 **TECH STACKS**

| **Category** | **TechStack** | **선정 이유** |
| --- | --- | --- |
| **Architecture** | Clean Architecture, MVI Pattern, 멀티모듈 | 계층 분리로 유지보수성 향상, 단방향 데이터 플로우로 예측 가능한 상태 관리, 모듈 단위 개발로 확장성 확보 |
| **Language** | Kotlin | Android 개발 표준 언어, 간결하고 안전한 코드 작성, Coroutines와 Flow 완벽 지원 |
| **UI** | Jetpack Compose, Material Design 3 | 선언적 UI로 개발 생산성 향상, 최신 디자인 시스템 적용, 상태 기반 UI 구성 |
| **Dependency Injection** | Hilt | 컴파일 타임 의존성 주입으로 성능 최적화, Android 생명주기 인식, 테스트 용이성 |
| **Network** | Retrofit, OkHttp, Kotlinx Serialization | RESTful API 통신 최적화, 네트워크 로깅 및 인터셉터 지원, 타입 안전한 JSON 직렬화 |
| **Asynchronous** | Coroutines, Flow | 비동기 작업 간소화, 메모리 효율적인 스트림 처리, UI 반응성 향상 |
| **Image Processing** | AsyncImage, Base64 Encoding/Decoding | 효율적인 이미지 로딩, 갤러리/카메라 연동, 서버 전송용 Base64 변환 |
| **State Management** | StateFlow, SharedFlow | 생명주기 인식 상태 관리, Hot Stream으로 Effect 처리, UI 상태 일관성 보장 |
| **Navigation** | Navigation Compose | 타입 안전한 네비게이션, Compose와 완벽 통합, 백스택 관리 |
| **Local Storage** | DataStore, Room (선택적) | 키-값 저장소로 설정 관리, 구조화된 데이터 캐싱 |
